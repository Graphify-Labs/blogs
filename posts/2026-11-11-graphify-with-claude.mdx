To use Graphify with Claude, connect the Graphify connector from Anthropic's Connectors directory, or add the hosted MCP server to Claude Code with one command. Both sign you in with OAuth, so there is no API key to paste. Claude can then search your indexed repositories, follow callers and dependencies, and check what a change reaches.

Graphify is a [code knowledge graph](/blog/what-is-a-code-knowledge-graph): it turns your repositories into a map of functions, files, calls and imports that Claude can query over MCP. Claude is where many developers first try it. New to Graphify? [Create your account](https://app.graphify.com/signup) free while you connect.

## What can Claude do with Graphify?

Claude can ask Graphify's code knowledge graph about your repositories instead of searching them file by file. With Graphify connected, Claude can:

- find a symbol and the files around it
- see what calls a function, and what a function calls
- trace how one symbol reaches another
- find the tests linked to a piece of code
- judge what a change is likely to reach

The graph is built from the repositories you connect. Functions, classes and files are the nodes, and calls and imports are the edges between them. Claude picks the tool that fits your question. You will see names such as `list_repositories`, `graphify_find`, `graphify_callers`, `graphify_callees`, `graphify_trace`, `graphify_tests_for` and `graphify_impact` in the tool requests. Each answer comes with source locations, so you can open the file and line behind it.

## Why do developers use Graphify with Claude?

Developers pair Graphify with Claude because Claude can ask the graph about structure instead of reading its way through the repository. Without a graph, Claude works out how code connects by opening files and searching for names, one result at a time. With Graphify connected, Claude asks a structural question, such as who calls this function, and gets the connected symbols back with their locations.

That is why so many creators show Graphify with Claude. Claude reads the relationships from the graph instead of opening and grepping file after file to piece them together. If you want the background on what fills Claude Code's context, read [what fills the Claude Code context window and how to keep it lean](/blog/claude-code-context-window-what-fills-it-and-how-to-keep-it-lean).

## Which Graphify setup is right for the Claude app you use?

Use the directory connector in Claude.ai, the desktop app and mobile, and use either that connector or one `claude mcp add` command in Claude Code. Both paths reach the same server and the same graph.

| Where you use Claude | How you connect | Full guide |
| --- | --- | --- |
| Claude.ai, the Claude desktop app, Claude mobile | Connect Graphify from Anthropic's Connectors directory, then turn it on in each chat | [Graphify for Claude](https://docs.graphify.com/integrations/claude-ai) |
| Claude Code signed in with your Claude account | The connector you added appears under `/mcp` | [Graphify for Claude Code](https://docs.graphify.com/integrations/claude-code) |
| Claude Code signed in with `ANTHROPIC_API_KEY`, Bedrock or another provider | Run `claude mcp add` in a terminal | [Graphify for Claude Code](https://docs.graphify.com/integrations/claude-code) |
| The Claude desktop app's Code tab or an IDE extension, with no `claude` command | Add Graphify to `~/.claude.json` | [Graphify for Claude Code](https://docs.graphify.com/integrations/claude-code) |

## What do you need before you start?

You need a Graphify account, at least one indexed repository and a Claude account.

- **A Graphify account.** If you don't have one yet, you can create one for free while connecting. The Free plan covers up to 3 repositories and needs no card. See [plans and pricing](https://docs.graphify.com/platform/support/pricing).
- **At least one repository with the status Indexed.** The [quickstart](https://docs.graphify.com/platform/quickstart) connects GitHub and starts indexing.
- **A Claude account.** On Team and Enterprise plans, an Owner adds the connector for the organization, and members then connect with their own account.

## How do I connect Graphify to Claude?

Open Graphify in Anthropic's Connectors directory, connect it, and turn it on in each chat. A connector is how Claude reaches a service you already use, and this one points Claude at Graphify's hosted MCP server. Open [Graphify in the Claude directory](https://claude.ai/directory/graphify) and follow these steps:

1. Select Connect to Claude and finish the Graphify sign-in in the browser. Or open Customize, then Connectors, select Discover, and search for Graphify.
2. Pick the workspace that holds your repositories.
3. In a chat, select the plus button, then Connectors, and turn Graphify on. The toggle is per chat.
4. Ask about your indexed code. The first tool call may ask you to select Allow once or Always allow.

If you don't have a Graphify account yet, you can create one while connecting. Create a workspace, connect GitHub and enable a repository before you expect code answers.

On a Team or Enterprise plan, an Owner sees Connect for your team and can also choose Connect just for me. Members may see Request until the connector is available for the organization. The same connector works in the Claude desktop app and on Claude mobile once you have connected it.

Not using the directory listing? Open Customize, then Connectors, select Add, then Custom and Web, and enter the server URL. You still sign in with OAuth.

```text
https://api.graphify.com/mcp
```

## How do I install Graphify in Claude Code?

Install Graphify in Claude Code by using the connector you already added, or by running one `claude mcp add` command. Pick one of them.

### Can Claude Code use the connector I already added?

Yes, when Claude Code is signed in with the same Claude account. Open `/mcp`. Connectors from claude.ai appear in that list. Complete authentication if it still asks, then ask Claude Code to list your Graphify repositories.

Those connectors load for a Claude account login. They do not load when `ANTHROPIC_API_KEY`, Bedrock or another provider is the active login. Run `/status` if `/mcp` does not list the connector, then `/login` with your Claude account, or add the server as below.

### How do I add Graphify as an MCP server in Claude Code?

Run one command in a terminal, not inside a Claude Code session:

```bash
claude mcp add --transport http --scope user graphify https://api.graphify.com/mcp
```

`--scope user` adds Graphify for your user, so it works in every project. The hosted server is per account, not per repository. To keep it to one folder, drop `--scope user` and Claude Code uses local scope.

Use one path. If a local entry and a claude.ai connector point at the same URL, Claude Code keeps the local entry and lists the connector as hidden.

### How do I share Graphify with my team in Claude Code?

Commit a `.mcp.json` at the repository root, and everyone who clones the repository gets the server:

```json
{
  "mcpServers": {
    "graphify": {
      "type": "http",
      "url": "https://api.graphify.com/mcp"
    }
  }
}
```

Each teammate approves the project server once, then signs in from `/mcp`.

### What if there is no claude command?

Edit `~/.claude.json` and add Graphify under the top-level `mcpServers` key. The Claude desktop app's Code tab and the IDE extensions run their own copy of Claude Code, so a terminal may answer `command not found: claude`. You don't need to install the CLI. The desktop app and the CLI read the same `~/.claude.json`.

1. Quit the desktop app or close the Claude Code session.
2. Back up the file with `cp ~/.claude.json ~/.claude.json.bak`.
3. Add `graphify` under the top-level `mcpServers` key. Create the key if it is missing and leave every other key as it is.

```json
{
  "mcpServers": {
    "graphify": { "type": "http", "url": "https://api.graphify.com/mcp" }
  }
}
```

Keep `"type": "http"`. Without it, Claude Code treats the entry as a local command and skips it. Claude Code loads servers when a session starts, so open a new session before you sign in.

## How do I sign in to Graphify from Claude Code?

Run `/mcp`, select graphify and choose Authenticate. Adding the server does not sign you in, and until you do, Claude Code lists `graphify` as needing authentication.

1. Start Claude Code and run `/mcp`.
2. Select graphify and choose Authenticate.
3. Finish the sign-in in the browser window that opens, and pick the workspace that holds your repositories.

## Does Graphify really work with Claude, and how do I check?

Yes, and you can confirm it in a minute. Graphify is working when `claude mcp list` shows graphify as Connected and `list_repositories` returns your repositories. Run `claude mcp list` in a terminal, then paste this into Claude Code:

```text
Use Graphify's list_repositories tool and show the repositories I can access. If the tool fails, report the error instead of guessing.
```

In a Claude chat with Graphify turned on, ask for the same list:

```text
List the repositories I can access in Graphify. If a tool fails, report the error instead of guessing.
```

The list should match the workspace you chose at sign-in. To point Claude Code at one repository by default, add `?repo=owner/name` to the endpoint, for example `https://api.graphify.com/mcp?repo=Graphify-Labs/graphify`. A repository named in a request still wins. The [verify connection guide](https://docs.graphify.com/platform/verify-connection) has more test prompts.

## What should I ask Claude first?

Pick a repository from the list, then name the symbol, file or area you care about and ask a structural question:

```text
Who calls the function that validates a session token?
```

```text
What would break if I changed this module's public interface?
```

```text
Summarize how requests reach the billing service.
```

```text
How does the login handler reach the session store?
```

```text
Which tests are linked to the code I'm about to change?
```

Open the source lines an answer cites before you change code. If you want Claude to reach for the graph on its own, add a short rule to your `CLAUDE.md`. The [make agents use the graph](https://docs.graphify.com/cookbooks/make-agents-use-the-graph) recipe has one, and so does [tell your agent to use the graph](/blog/tell-your-agent-to-use-the-graph).

## Is there a Graphify skill for Claude Code?

Yes. The open-source Graphify CLI installs a `/graphify` skill for Claude Code and builds the graph on your own machine. Install it, then open your project in Claude Code and enter `/graphify .`:

```bash
uv tool install graphifyy
graphify install --platform claude
```

The hosted connector above needs no install and keeps the graph in your Graphify workspace, rebuilt on every push to the default branch. [Graphify in Claude Code: hosted MCP or a skill?](/blog/graphify-claude-code-hosted-mcp-or-skill) compares the two, and the CLI is on [GitHub](https://github.com/Graphify-Labs/graphify).

## How do I fix common Graphify and Claude problems?

Most fixes come down to signing in from `/mcp`, keeping to one setup path, or turning Graphify on for the chat.

| What you see | What to do |
| --- | --- |
| `graphify` shows Needs authentication | Run `/mcp`, select graphify, and choose Authenticate. |
| `/mcp` doesn't list the claude.ai connector | Run `/status`. Connectors from claude.ai load with a Claude account login, not with `ANTHROPIC_API_KEY`, Bedrock or another provider. Use `claude mcp add`, or `/login` with your Claude account. |
| The claude.ai connector is hidden | A local entry points at the same URL. Remove it with `claude mcp remove graphify` if you want the directory connector. |
| `command not found: claude` | You are in the desktop app or an IDE extension. Add the entry to `~/.claude.json`, then start a new session. |
| Graphify works in one project but not another | You added it at local scope. Run the add command again with `--scope user`. |
| Pending approval next to `graphify` | It comes from a project `.mcp.json`. Start `claude` in that repository and approve it. |
| Every Graphify tool appears twice | You have both a user scope entry and a project `.mcp.json` entry. Remove one with `claude mcp remove graphify`. |
| A Claude chat doesn't use Graphify | Select the plus button, then Connectors, and turn Graphify on for that chat. Approve the tool call if Claude asks. |
| The tools return no repositories | The repository is not indexed yet, or it is in a different workspace. Check Repositories and builds in Graphify. |
| Only a `graphify_setup` tool appears | Finish setup at app.graphify.com/onboarding: create a workspace, connect GitHub, enable a repository and wait until it is Indexed. Then start a new session. If tools still fail, disconnect and reconnect Graphify. |

## How does Graphify stay current while I work with Claude?

Graphify rebuilds the graph on every push to the default branch and re-processes only the files that changed, so Claude reads a graph that follows your repository. [How to keep a code graph fresh on every push](/blog/keep-a-code-graph-fresh-on-every-push) explains what triggers a build.
