GitHub's [Octoverse 2026](https://octoverse.github.com/) is out, and [Graphify-Labs/graphify](https://github.com/Graphify-Labs/graphify) is in it. GitHub named Graphify one of the top open source projects on GitHub in 2026.

![Octoverse 2026: Graphify-Labs/graphify was a top open source project on GitHub in 2026.](thumb.png)

In the [Octoverse 2026 report](https://github.blog/news-insights/octoverse/octoverse-commits-pushes-reach-new-highs-in-2026-as-developers-build-with-agents/), GitHub lists the most-engaged open source repositories of the year. Graphify is No. 7 on the single-vendor and product-led list, alongside projects like microsoft/vscode, anomalyco/opencode, and BerriAI/litellm. The Octoverse year ran from 1 October 2025 to 30 September 2026.

The first commit was 5 April 2026. Less than six months later, Graphify is in GitHub's own report on the year in open source.

## Octoverse, built by the community

A list like this is about engagement, and engagement is people. People who starred the repository, opened issues, sent pull requests, answered questions in Discord, and wrote about Graphify on their own blogs.

On 29 October 2026, [Graphify-Labs/graphify](https://github.com/Graphify-Labs/graphify) had more than 137,000 GitHub stars and more than 13,000 forks. The `graphifyy` package was downloaded more than 1.6 million times from PyPI in the last month alone.

We wrote about [125,000 GitHub stars](/blog/125000-github-stars) two weeks ago, and about [8 million PyPI downloads](/blog/eight-million-downloads-in-six-months) before that. Octoverse is the same story told by GitHub.

## What stays the same

- Code is parsed on your machine, from the files in the repository.
- Every relationship is tagged [`EXTRACTED` or `INFERRED`](/glossary/confidence-tags).
- The result is a [knowledge graph](/blog/what-is-a-code-knowledge-graph) your assistant can query and walk.
- The project is Apache 2.0. That stays.

Type `/graphify` in Claude Code, Cursor, Codex, Gemini CLI, or Copilot, and the map of your codebase comes back.
