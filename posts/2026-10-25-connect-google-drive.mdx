A Google Drive folder can sit in the same graph as the repositories already in a workspace. The Google account that connects Drive picks the folder, including a folder on a shared drive. After the first build, Open graph, Wiki, and Ask can read those documents. People who cannot open the file in Google Drive can still search it. Drive still decides who can open the original.

The grant is read-only. The connect dialog says "Read-only access. Graphify never edits your files." It asks Google for Drive access and for the email that identifies the account. It does not ask for Gmail or Calendar.

## What does a Google Drive folder become?

Graphify stores the folder as a repository, the same kind of object as a GitHub repo. The external id is the folder id. The name reads Google Drive, then the folder name. The first build is queued as soon as the folder is added. Later, Graphify lists the files again and builds a new graph only when that list has changed.

The files it reads are Google Docs, Sheets, and Slides, plus PDF, Word, Excel, PowerPoint, CSV, Markdown, text, and image files. A file it cannot read stays in the folder details, with a reason next to the name. The other files in the folder stay searchable. The details say that list may be incomplete.

A [knowledge graph](https://graphify.com/glossary/knowledge-graph) is the map those documents join. [What is a code knowledge graph?](https://graphify.com/blog/what-is-a-code-knowledge-graph) is the same map for a repository. A Drive folder is searched from that map. Pull request review stays on GitHub and GitLab repositories.

## Who can search a file they cannot open?

The Drive list says the folder is visible to everyone in the workspace. Adding it requires a checkbox: "I understand everyone in this workspace can read this folder's contents." Graphify rejects the add until that box is ticked.

[Notion AI](https://www.notion.com/help/notion-ai-connectors-for-google-drive) surfaces a Google Drive file only to someone who can already open it. [Glean](https://docs.glean.com/connectors/native/gdrive/about) says a person sees documents they have permission to access. [Dust](https://docs.dust.tt/docs/user-documentation/admins/connections-management/google-drive) syncs what the connected admin can open in Drive, and that page does not say Dust re-checks each member at question time. Graphify matches Dust. The connected account picks folders it can open, and the workspace searches what was built. The checkbox says so in the product.

Open in Drive is the way back to the file. Drive decides who can open it there.

The person who connected the account is the person who can add folders. Another owner or admin changes the account from Connection settings. A different Google account stops syncing the folders already added. Those folders are added again from the new account. Reconnecting the same account leaves them in place.

## Why does Checked move when Last synced does not?

Checked is the last time Graphify listed the folder. Last synced is when the latest successful build finished. After a successful check, the next check waits 15 minutes. If the new list matches the graph already being served, the row can say Up to date while Last synced stays put. Changes found means the list has moved and the served graph is behind it.

A failed check makes that folder wait longer, up to 6 hours. Other folders keep their own schedule. When Drive does not respond, or a folder takes too long to check, leave the folder enabled. Graphify retries on its own.

Before the first successful build, the row says "Graph, Wiki, and Ask are available after the first successful sync."

## What remains after you stop?

Stop syncing on one folder, or disconnect the account, and Graphify stops reading. The graph already built stays searchable. Disconnect revokes the grant. The toast says "Google Drive disconnected. Folder syncing has stopped."

Google Drive on [Graphify Cloud](https://app.graphify.com) is on a paid workspace. Plans are on [Graphify pricing](https://graphify.com/pricing). The clicks, from Connectors to the folder picker, are on [Connect Google Drive](https://docs.graphify.com/platform/google-drive).
