Open-source Graphify, published on PyPI as graphifyy, has passed 10 million downloads. On 6 November 2026, [pepy.tech](https://pepy.tech/projects/graphifyy) reported 10,138,357 downloads of graphifyy on PyPI, including 2,030,697 in the last 30 days. The first release, 0.1.1, was uploaded on 4 April 2026 (UTC), and [PyPI](https://pypi.org/project/graphifyy/) lists 271 versions.

The latest version on that pepy.tech page is 0.9.103, released 5 November 2026.

## What Graphify does

Graphify turns a folder of code into a knowledge graph your coding agents can query. The graph records functions, classes, files, and the links between them, so an answer can point at a file and a line. [What is a code knowledge graph?](/blog/what-is-a-code-knowledge-graph) is the longer explanation. In October we wrote about [Eight million downloads in six months](/blog/eight-million-downloads-in-six-months).

## What the download count does not mean

pepy.tech says its download chart includes CI traffic, and the same project can be installed many times, so 10 million downloads are not 10 million people. The total is an install count. It is not a measure of how many teams use Graphify.

[pypistats.org](https://pypistats.org/packages/graphifyy) is a second public counter. On 6 November 2026 its package page showed 79,294 downloads in the last day, 483,662 in the last week, and 1,630,115 in the last month. That page plots one line with mirrors and one without. Those figures are not pepy.tech's, and they are not a headcount either.

The chart covers 5 August to 3 November 2026. It stops on 3 November and has not been redrawn for the 6 November total.

## Thank you

Thank you for installing Graphify, for issues and pull requests, and for questions in [Discord](https://discord.gg/graphify). The download count does not record that work. It only records installs. Open-source Graphify stays under the Apache 2.0 license. The code is at [Graphify-Labs/graphify](https://github.com/Graphify-Labs/graphify).

## How to try Graphify

Open the hosted Graphify app at [app.graphify.com](https://app.graphify.com) and connect a repo. To run it on your machine, install open-source Graphify with uv tool install graphifyy.

```bash
uv tool install graphifyy
```

The steps for uv, pipx, and a virtual environment are in [Install Graphify CLI with uv or pipx](https://docs.graphify.com/open-source/installation).
