Open-source Graphify, published on PyPI as [graphifyy](https://pypi.org/project/graphifyy/), has passed 10 million downloads. On 6 November 2026, [pepy.tech](https://pepy.tech/projects/graphifyy) reported 10,138,357 downloads, including 2,030,697 in the last 30 days. The first release, 0.1.1, was uploaded on 4 April 2026, and PyPI lists 271 versions.

In October we wrote about [eight million downloads in six months](/blog/eight-million-downloads-in-six-months). The work is the same. Graphify turns a folder of code into a knowledge graph, so you and your coding agents can ask questions of the repo you have.

## What Graphify is for

Coding agents write a lot of code and still start with a thin picture of the system they are editing. Graphify gives them a map: functions, classes, files, and the links between them. [What is a code knowledge graph?](/blog/what-is-a-code-knowledge-graph) is the longer explanation.

## Thank you

Thank you for installing Graphify, for the issues and pull requests, and for the questions in [Discord](https://discord.gg/graphify). Open-source Graphify stays Apache 2.0. The code is at [Graphify-Labs/graphify](https://github.com/Graphify-Labs/graphify).

## How to try Graphify

The hosted app is the quickest way in. Open [app.graphify.com](https://app.graphify.com), connect a repo, and ask a question.

To run open-source Graphify on your own machine:

```bash
uv tool install graphifyy
```

The steps are in [Install Graphify CLI with uv or pipx](https://docs.graphify.com/open-source/installation).
